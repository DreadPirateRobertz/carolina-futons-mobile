🔨 Build Commands — Run at Leisure

All builds on linux (pop-os). Metro, expo, npm — never run on Mac (OOM kills).

# SSH to linux build machine
ssh pop-os

# Navigate to project
cd ~/cfutons_mobile

# Pull latest main
git pull origin main

# Android build + install on Pixel 7 emulator
npx expo run:android -- --device cfutons_pixel7

# Screenshot all screens (run after emulator boots + app loads)
bash scripts/capture-screenshots.sh

# iOS sim build (Mac only — Xcode required)
npx expo run:ios

# Run tests (linux)
npx jest --passWithNoTests
