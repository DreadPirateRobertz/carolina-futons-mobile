Design Principles

Warm, Not Cold

Shadows use espresso (#3A2518), never gray or black. Backgrounds are warm brown, never pure black. The palette evokes Blue Ridge sunsets.

Editorial Typography

Playfair Display headings give a high-end magazine feel. Source Sans 3 body text is clean and readable. Together they say "premium, not generic."

Haptic & Motion

Every interactive element uses AnimatedPressable with spring scale + haptic feedback. Transitions feel physical and deliberate.

CTA = Sunset Coral

All primary CTAs use #E8845C (Sunset Coral). Never green, never blue. This is non-negotiable across all screens.
